# Satya Yamini Portfolio

A responsive personal portfolio website created from the resume.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation

## Run in VS Code
1. Extract/open this folder in VS Code.
2. Open `index.html`.
3. Right-click the file and choose **Open with Live Server** if you have the Live Server extension.
4. Before publishing, replace the GitHub placeholder with the actual GitHub profile URL.

No build tools or npm installation are required.
